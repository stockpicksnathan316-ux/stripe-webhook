## 🚀 The Project
We built an **AI-powered stock momentum scanner** that predicts 5‑day price direction using an ensemble of XGBoost, Random Forest, and LightGBM. It's a Streamlit app with:

### Core Features
- Live predictions (probability of UP move) for any ticker.
- Multi‑ticker scanner (150+ stocks) with sector filters.
- Color‑coded signals: green (>65% bullish), red (<35% bearish).
- Backtest expander with equity curves and win rate.
- Macro data integration (VIX, 10‑year yield, oil futures, sector ETFs).
- Ensemble model voting on every prediction.
- Paywall with free tier (5 scans) and Stripe $20/month subscription.
- Permanent Pro status stored in Supabase, checked on every load.
- Ticker list loaded from `tickers.csv` for easy updates.

### Technical Stack
Python 3.14, Streamlit 1.54.0, yfinance, pandas, plotly, xgboost, lightgbm, scikit‑learn, ta, stripe, supabase, render, git/GitHub.

Webhook: Flask app on Render listens for Stripe events and updates Supabase.

Database: Supabase (PostgreSQL) with `paid_users` table.

Secrets managed via Streamlit Cloud secrets and Render env vars.
